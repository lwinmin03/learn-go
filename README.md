# Learn Go From Saturngod's Book 

This repository documents my journey learning Go from the book *"The Go Programming Language"* (or any Go book).

## Goals
- Learn Go fundamentals, functions, structs, concurrency, and advanced topics
- Solve exercises per chapter
- Build mini-projects to reinforce learning

## Structure
- `book/` → Chapter summaries and key points
- `exercises/` → Coding exercises per chapter
- `projects/` → Mini-projects combining multiple concepts
- `notes/` → Mistakes, tips, and summaries

## Daily Plan
1. Read a chapter
2. Summarize key points in `book/chapter-XX.md`
3. Solve exercises in `exercises/chapter-XX/`
4. Build small project features using the concepts
5. Update notes in `notes/`
